## 고친 내용과 검증 범위

### 코호트에 실제 사용한 실행기·과제·fixture

실행 런타임은 `43e3b143cdfee0a8ae23f68808ebf850e99008bb`로 동결했다.

- **진행 중 취소:** 유효한 대용량 fixture를 사용하고 reading·analysis 단계, 실제 취소 dispatch, 저장 전후 digest를 연결했다. v7 ZIP은 57,961,041 bytes, 인식 JSON은 57,960,093 bytes로 제품의 64MiB 제한 안이다.
- **클릭·스크롤:** 현재 관측의 가시성·활성 상태·모달 소유권과 hit test를 확인한다. 활성 모달의 실제 본문을 스크롤하고 이동량과 배경 이동을 기록한다.
- **저장 실패:** 격리된 합성 데이터에 한 번만 적용하는 쓰기 오류와 원상 복구, 실제 재시도 조작, 저장 보존을 구분했다.
- **fixture:** 11개의 구별되는 보관 기록, 검색 가능한 12행 목록, 같은 계정의 비교 pair를 등록했다. 기존 fixture는 덮어쓰지 않았다.
- **과제·예산:** 기준별 필수 단계와 준비 순서, 샘플 내보내기 선행·삭제 후행을 명시했다. 64턴과 증가하는 체크포인트 한도를 적용하고 원본 관측은 유지했다.
- **판정·전송:** NBSP 정규화, 자기 업로드 시도에 연결된 증거, 실제 비교 화면의 설명, 제한된 실패 reason을 처리했다. 전송 후 불확실은 영구 guard로 보존하고 재전송·fallback하지 않는다.
