[종료 무결성 감사](terminal-cohort-integrity-review.md)는 27개 평가 세션의 등록 파일 **844개·22,414,369바이트**, 전체 32개 체크포인트·28개 저장 결과·27개 최초 판정의 봉인을 재확인했다. 제외 세션의 부분 증거는 이 844개 분모에 포함되지 않으며 별도 검토 기록에 보존했다. 17개 런타임·544개 fixture·319개 제품 소스·13개 빌드 파일과 저장된 전후 HTTP 6개 자산 핀은 일치한다. 이전 38개 큐의 작업·상태·문제·대기 연산 메타데이터 스냅샷도 불변이다.

소유 작업 그룹 **32개가 모두 종료**됐고 독립 프로세스 검사에서 잔존 그룹이 없다. 드라이버 종료 확인은 31개이며, 012/018은 강제 정리했고 014는 드라이버 확인 없이 그룹 종료가 확인됐다. 원래 불확실 동작을 다시 보내는 정리는 수행하지 않았다.

모델 기록은 **642개 논리 호출·651개 실제 시도**다. 수신 성공 649회, 전달 불확실 2회이며, 추가 9회는 이미 수신한 응답의 형식 보정이다. 불확실 요청 재전송은 0회, 유료 폴백은 0회이고 요청 경로는 승인된 `TOKENMAXX/deepseek-v4.1-flash-free` 하나다. 제공자 청구서를 검증했다는 뜻은 아니다. 보고서 작성·독립 검토는 새 모델·브라우저 호출과 큐 변경 없이 수행했다.

남은 실제 실행 공백은 개인정보 안내를 보이게 하는 단계 7건, 저장 실패 뒤 복구 1건, 그리고 평가 제외된 다섯 세션이다. 030의 누적 본문 상한 원인은 규명했지만 본문 축소·상한 변경은 구현하지 않았다. 014의 DOM 조회 제한과 025/029의 전달 불확실도 보존돼 있다. 이 코호트의 남은 공백에 대한 추가 수정이나 새 실제 실행의 개선 효과는 이번 결과에서 주장하지 않는다.

## 범위와 증거의 한계

- 021–024의 UNKNOWN 기준은 원본 PRD·배정 의무·실행 행동·동결된 테스트에 따라 legacy 마이그레이션과 제외 경로로 평가했다. known-empty 문장은 잘못된 fixture 대체를 막는 분류 설명이다. 별도 known-empty 파일 가져오기는 실행·가산하지 않았다. [독립 범위 해석](unknown-criterion-scope-review.md).
- 이 네 세션의 후속 비교는 실제 현재→이전 순서였다. 지정된 과제 순서와의 차이를 보존하고, 그 실제 한 행 비교에 한정해 IDENTITY를 판정했다. 다른 세션에서 확인한 정방향 원인 문구 결함의 해결 근거로 사용하지 않았다.
- 취소 관측창은 013/015/016에서 각각 1,115/1,105/1,085ms다. 이는 정확한 취소 전달 시각이 아니다. 실제 활성 상태·전달·저장 불변은 등록 행동 사실로 검증했으며, PNG는 업로드 전/취소 후 캡처다.
- 불확실 요청의 재전송, 이전 세션 판정의 자동 이식, N/A의 실행 완료 가산은 수행하지 않았다. 무료 경로·요청 무결성·이전 큐 메타데이터 보존·소유 브라우저 종료는 위 전역 감사의 명시된 범위로 검증했다.
