# 맥미니 검증 기록 (2026-10-12)

실제 XCTest 캡처를 가져오는 iOS 어댑터를 검증하고, 목록의 행별 버튼을 하나의 선택지 묶음으로 세던 CG-01 오탐을 수정했다. UniClub에서는 입력란의 접근성 이름과 기존 Figma의 미리보기 안내를 보완했다. 스킬 PR #5와 UniClub PR #1은 Draft/open으로 유지하며 병합·배포·릴리스·전역 스킬 설치는 진행하지 않았다. 사용자 요청에 따라 iPhone 인증 작업은 보류했다.

CG-01은 렌더링되고 사용 가능한 제어 요소의 DOM 분기를 기록한다. 측정된 그룹, 그룹 없음, 측정 불가를 구분하고, 새 측정의 null을 과거 추정 방식으로 대체하지 않는다. 오래된 캡처의 추정 방식과 실제 선택 대안인지 확인이 필요한 부분은 보고서에 표시한다. 임계값·모델·평가 정답은 바꾸지 않았다.

game-desktop 입력 10개는 이전 실행과 바이트가 같으며 기본 프로필 14개와 seed 11을 유지했다. 이번 실행은 검증 작업 소유의 loopback 브라우저 서버에 연결했고, 이전 평가에는 `REMORSEARCH_BROWSER_WS`가 없었다. 이 환경 차이를 보존하며 전체 수치 변화의 원인을 모두 이번 패치로 확정하지 않는다. 두 admin 변형에서 행별 버튼을 12개 선택지로 세던 CG-01/P3 경고가 사라진 것은 실제 캡처로 확인했다. 모든 심각도를 합한 clean 경고 수를 P0–P2 오류율로 해석하지 않는다.

## 네이티브·Figma·접근성

iOS 어댑터는 캡처 UUID·첨부·해시·PNG 크기·실제 앱 정보를 연결한다. 원본 XCTest의 실패와 `success: null`을 보존했다. 해당 캡처 분석은 `degraded`, 제약 30개, 관측 0개다. 표시 여부·서체·색상은 미측정 상태이며, 호출자가 입력한 시나리오 이름만으로 과업 성공을 확정하지 않는다.

Figma 파일 `mJCdKkmBVVpnya8ImOsT6G`의 기존 서버 버전 `2398320552837187712`에서 `18:650`과 `108:727`을 확인했다. `108:745`의 읽기 전용 안내를 예시 콘텐츠 뒤에 복원하고, Caption·기존 secondary 토큰과 자연스러운 세로 확장을 적용했다. 게시본·초안·히스토리와 native 서체는 유지했다. 지속적인 시각 제목, 주요 버튼·컴포넌트 구성 차이와 전체 픽셀 정합은 남아 있다.

[UniClub 최종 검증 기록](https://github.com/remorser58/UniClub/blob/96c0b6aae1293c8ee5b6b423ba76bba00562957b/docs/release/remorsearch-validation-20261012.md)에서 입력란 5개의 실제 TextField 이름, 미리보기 안내, 키보드 편집 2건, 저장값 유지와 버전 기록을 확인했다. 폼 12개·미리보기 8개 VoiceOver 발화가 기대 문구와 일치했고 상태를 복원했다. 최종 XCTest는 접근성 감사 10건으로 실패(exit 65)를 유지한다. 안내는 기본 글자 크기에서 모두 보이며 큰 글자 조건의 잘림 경고는 남았다. 원본 캡처 27장은 모두 430×932pt·1290×2796px@3x다.

데모의 별도 진단은 20건의 원본 감사와 VoiceOver 오류를 보존했다. DEBUG 표식 6건, 고정 크기 영향을 받는 Dynamic Type 8건, 요소 정보가 없는 진단 4건, 비활성 저장 버튼 대비 1건, 일부만 보이는 계정 제목 대비 후보 1건으로 구분했다. 데모에 추가했던 부적절한 감사 assertion은 제외하고 기존 메서드를 그대로 유지했다. 소유자 메서드·공용 helper는 최종 실행 당시와 같으며 최종 소스의 `build-for-testing`을 통과했다.

앞선 Air·15Pro의 실제 캡처 가져오기는 미지원 기기 모델로 거부했다. 별도 iPhone 15 실행에서는 PNG 폭 1178px이 기대 1179px과 달라 기하 검증에 실패했다. 기기 근사 매핑·리스케일은 넣지 않았고 모든 실패 자료를 보존했다.

## 남은 검증

iPhone 13 연결·개발자 모드는 확인했고 Xcode 계정·Team은 사용자가 화면에서 확인했다. 인증·서명·실기기 설치는 사용자 요청에 따라 보류했다. 실기기 VoiceOver 전체 과업, 하드웨어 키보드, 남은 접근성 경고의 재현·수정이 남아 있다.

heldout-2의 봉인 입력은 알려진 보관소에서 찾지 못했다. 새로 재구성하지 않았으며 기존 noise 1.75(기준 0.35), H5 C3 0.083·C4@14 0.125의 실패 판정을 유지한다. game-desktop 결과는 알려진 데이터의 회귀 검사다. 새 데이터 일반화와 실제 사람의 수행 개선은 미검증이다.

완성도 시나리오 M01–M08 전체를 충족한 것은 아니다. 실제 native 과업 범위와 도구 실행을 확인했으며, 호스트 채택·다중 호스트·세션 복구 검증은 남아 있다. 새 하니스·벤치마크·테스트 플랫폼은 만들지 않았다.
