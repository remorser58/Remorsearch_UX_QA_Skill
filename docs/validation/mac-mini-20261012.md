## 남은 한계

1. 실물 iPhone 13 연결과 개발자 모드는 확인했다. 무서명 iphoneOS 빌드는 성공하고 arm64 무서명 app을 만들었다. Xcode 계정·팀 등록은 사용자가 확인했고 마지막 조회에서 유효한 Apple Development identity는 0개였다. 사용자가 인증서를 만드는 동안 실기기 VoiceOver 호출을 준비하고 있으며 실기기 실행 기록은 아직 없다.
2. 완성도 시나리오 M01–M08 전부가 이번 실행으로 충족된 것은 아니다. 실제 native 플로우 범위만 확인했고 호스트 채택, 다중 호스트, 세션 복구 성숙도는 남아 있다.
3. 전체 제품 PASS가 아니다. UniClub PR #1은 Draft/open을 유지한다.
4. 새 하니스, 벤치마크, 테스트 플랫폼을 만들지 않았다.

## 재실행

지원 런타임(Python 3.12.14, Node 22.23.3)을 먼저 찾는다.

```sh
python3 skills/remorsearch-ux-qa/scripts/find_runtime.py
python3 -m unittest discover -s tests -p 'test_*.py'
node skills/remorsearch-ux-qa/drivers/web/selftest.mjs --keep
```

기록된 568 통과 실행은 `ERGOQA_PYTHON`, `PYTHONPATH`, `REMORSEARCH_BROWSER_WS`를 지정했다. 위 명령만으로 같은 조건이 보장되지 않고 환경 값은 `browser-report.json`에 있다.
